# 🎵 Music Streaming API

A **RESTful backend API** for a music streaming platform built with **Node.js, Express.js, and MongoDB**.

Artists can upload and manage their music, while listeners can browse, search, filter, and stream music.

This project is focused on building a **secure, scalable, and well-structured backend** using modern backend development practices.

## 🚀 Features

- 🔐 JWT & bcrypt Authentication
- 👥 Role-Based Authorization
- 🎤 Artist Music Upload & Management
- 🎧 Music Streaming
- 🔄 CRUD Operations
- 🔎 Search & Filtering
- 🍪 Cookie Authentication
- 🌐 RESTful API
- 🛡️ Protected Routes
- 📁 File Upload Support
- 🗄️ MongoDB Database Integration
- ⚡ Express.js Backend

## 🛠️ Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB**
- **Mongoose**
- **JWT**
- **bcrypt**
- **cookie-parser**
- **Multer**
